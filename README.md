# sspai-writer

少数派风格 Claude Code 写作 Skill。基于 87 篇少数派优质长文，系统化蒸馏出可复现的 AI 写作工作流。

## 这是什么

一个面向中文深度内容的 AI 辅助写作 Skill，针对 [Claude Code](https://claude.ai/code) 设计。不是简单的 prompt 模板——它是一套经过实战验证的**人机协作流程**，包含：

- **风格蒸馏体系**：分析 87 篇少数派头部文章的叙事结构、语气节奏、论证方式，提炼出可量化的写作规范
- **四层质检流程**：禁用词扫描 → 风格一致性检查 → 内容准确性验证 → 活人感评估
- **封面生成工具**：`generate_cover.py` 用程序化方式生成公众号风格封面图，支持自定义标题、纹理、配色
- **协作协议**：`CLAUDE.md` 中明确定义了人和 AI 的分工边界——什么由人拍板、什么由 AI 执行、什么绝对不能碰

## 为什么存在

大多数 AI 写作工具的问题：

1. **风格不可控** — 输出千篇一律，没有作者的个人声音
2. **流程不透明** — AI 做了什么、人需要修正什么，没有清晰的分工
3. **质量无标准** — 写完了不知道好在哪里、差在哪里

这个 Skill 的解法是：**把"好文章"拆解成可执行的规则，让人机各司其职。**

## 工作流

```
素材 → AI 结构化扩写 → 人二次改写 → AI 四层质检 → 人终审定稿
```

| 阶段 | 谁做 | 做什么 |
|------|------|--------|
| 素材输入 | 人 | 核心观点 + 个人经历 + 情绪节点 |
| 扩写 | AI | 补背景知识、找证据类比、梳理结构 |
| 二次改写 | 人 | 加入个人声音、补充真实细节 |
| 质检 | AI | 禁用词 / 风格 / 内容 / 活人感 四层检查 |
| 定稿 | 人 | 最终审核、发布 |

> 详细的红线规则和质检标准见 [CLAUDE.md](CLAUDE.md)。

## 技术栈

- **运行时**：Claude Code（CLI 编码 Agent）
- **封面生成**：Python + Pillow，程序化纹理渲染（织物纹理、丝线叠加、暗角效果）
- **协议格式**：Markdown + YAML frontmatter

## 项目结构

```
sspai-writer/
├── CLAUDE.md              # 协作协议（人机分工、红线、质检标准）
├── README.md              # 你在这里
├── generate_cover.py      # 封面图生成器（900×1200 程序化渲染）
└── 作品/                   # 已发布的成稿（gitignored）
```

## 设计原则

1. **人做人的事，AI 做 AI 的事** — 核心创意、情绪表达、真实经历永远由人主导
2. **可审计性** — 每一步输出都可以追溯到输入，修改有据可查
3. **可组合** — Skill 模块化，可以和其他 Claude Code Skills 组合使用
