# writer — 个人写作工作区

公众号长文 / 内容输出的工作区。存放成稿、素材、辅助脚本。

## 目录结构

- `作品/` — 已完成的稿子
- `generate_cover.py` — 封面图生成脚本

## 协作分工

按 [khazix-writer](https://github.com/KKKKhazix/khazix-skills/tree/main/khazix-writer) skill 原作者的分工:
- 我提供:素材 + 核心观点 + 个人经历 + 情绪节点
- AI 做:补背景知识 / 找证据类比 / 梳理结构 / 按我定好的角度扩写
- 我二次改写,AI 自检,我终审

详细分工和红线见 `CLAUDE.md`。
