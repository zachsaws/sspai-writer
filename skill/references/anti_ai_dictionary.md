# Anti-AI Dictionary: 表达耻辱柱与逻辑禁区

## 1. 表达黑名单 (Vocabulary Blacklist)

以下词汇一旦出现，文章的"AI 味"会瞬间超标，必须无条件替换或通过细节描写消解：

| AI 常用词 (Ban) | 替换方案 / 消解方式 (Fix) |
| :--- | :--- |
| **"本质上是..."** | 描述具体的运作机制或后果。 |
| **"这不仅仅是...更是..."** | 直接说它的多重影响，不要用这种排比句强行拔高。 |
| **"不容忽视的是..."** | 默认读者很聪明，如果你写得够具体，读者自然不会忽视。 |
| **"底层逻辑" / "维度"** | 换成"规则"、"习惯"、"视角"或具体的行业术语。 |
| **"总之" / "综上所述"** | 用一个具体的动作（如"关上电脑"、"走出办公室"）或一个耐人寻味的场景收尾。 |
| **"随着...的发展"** | 设定一个具体的时间锚点（如"那是 2023 年的一个雨天"）。 |
| **"在...的背景下"** | 直接描述具体情境，不要铺垫宏大背景。 |
| **"值得注意的是"** | 删掉。如果值得注意，你的写作本身应该让读者注意到。 |
| **"从某种程度上说"** | 删掉。模棱两可的缓冲词削弱论证力度。 |
| **"毋庸置疑" / "毫无疑问"** | 删掉。真正的毋庸置疑不需要强调。 |

## 2. 句式耻辱柱 (Syntactic Hall of Shame)

### A. 爹味设问 (The Preachy Interrogative)
*   **示例**："你是否也在思考...？"、"如果你还在纠结...？"
*   **诊断**：强行代入读者的视角，带有虚假的互动感和说教意味。
*   **修正**：描述你自己的痛苦，读者自然会共鸣。"那几天，我盯着屏幕，那种纠结感几乎要把我吞没。"

### B. 宏大叙事空降 (The Grand Narrative Drop)
*   **示例**："这预示着一个新时代的到来。"、"这不只是一次模型发布，这是一场革命。"
*   **诊断**：在没有证据支持的情况下给结论，显得极其空洞。
*   **修正**：描述具体的小变化。"那天之后，我发现公司茶水间里，大家讨论的主题从'怎么写代码'变成了'怎么写提示词'。"

### C. 线性流水账起手 (The Linear Chronological Start)
*   **示例**："今天下午，当我看到...推送时..."
*   **诊断**：平铺直叙，缺乏戏剧张力。
*   **修正**：从冲突或感官细节切入。"手机在兜里猛地震了一下，那种频率我知道，是 DeepSeek 又在搞事情了。"

### D. 列表式总结 (The Bullet-Point Conclusion)
*   **示例**：结尾用"第一...第二...第三..."或"一是...二是...三是..."总结全文。
*   **诊断**：把文章降格为 PPT，破坏阅读流畅性。
*   **修正**：用一个场景、一个动作、或一个反问收尾。"

### E. 免责声明式开头 (The Disclaiming Opening)
*   **示例**："本文仅代表个人观点，如有不妥请指正。"
*   **诊断**： preemptive 的自我削弱，显得不自信。
*   **修正**：直接开始。你的观点就是你的观点，不需要提前道歉。

## 3. 逻辑禁区 (Logic No-Go Zones)

1.  **禁止"完美闭环"**：不要试图给出一个无懈可击的完美方案。现实生活是破碎的，承认方案的局限性、承认自己的犹豫，反而更有"人味"。
2.  **禁止"过度解读"**：不要给每一个简单的动作都赋予一个深刻的社会学意义。有时候，喜欢一个包仅仅是因为它够"脏"，这种纯粹的感性比强行拔高更动人。
3.  **禁止"副词堆砌"**：尽量删掉"非常"、"极大地"、"深刻地"。用具体的量化数据或动作来替代。
    *   *Bad*: 这个 App 极大地提高了我的效率。
    *   *Good*: 原本需要三小时的繁杂对账，现在被 MOZE 压缩到了一个红绿灯的时间。
4.  **禁止"假两难"**：不要制造虚假的二元对立（"要么 A，要么 B"）。现实往往是"A 和 B 都有问题，C 是第三条路"。
5.  **禁止"因果简化"**：复杂现象 rarely 有单一原因。避免"因为 X，所以 Y"的简单归因。

## 4. 负样本典型案例解构

### 案例 1：DeepSeek 发布评价
> "今天下午，当我看到 DeepSeek V10 的发布推送到手机上时... 这不只是一次模型发布... 过去一年，我们习惯了..."
*   **罪状**：线性起手、宏大叙事、背景板垫场。
*   **重塑思路**：从"我"的即时反应（可能是刚好弄翻了咖啡，或者正在处理一个棘手的 Bug）切入，通过个人体验的打断来引出发布。

### 案例 2：账号纠结
> "如果你还在纠结 PRO 账号为什么没了... 大厂把 Coding Plan 强行切成 Token Plan，本质上是..."
*   **罪状**：爹味设问、过度解读（本质上是...）。
*   **重塑思路**：描述扣费短信发来时的那种"被背叛感"，以及自己翻遍了所有协议寻找答案的过程。

### 案例 3：AI 效率论述
> "随着 AI 技术的不断发展，我们的生活正在发生深刻的变化。值得注意的是，AI 不仅极大地提高了工作效率，更从根本上改变了我们的思维方式。"
*   **罪状**："随着...的发展"、"值得注意的是"、"极大地"、"从根本上"——五毒俱全。
*   **重塑思路**："我第一次用 Claude 写完周报只花了 8 分钟，那省下的 52 分钟我用来发呆，发现发呆比写周报更让我焦虑。"
