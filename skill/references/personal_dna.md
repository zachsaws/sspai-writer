# 个人创作 DNA (Persona Memory)

这是基于用户深度语料萃取的"灵魂镜像"。

## 1. 核心叙事癖好

*   **物理锚点**：倾向于从"物理约束"（重量、算力、续航、交互路径）出发去拆解产品，拒绝宏大概念。
*   **冷峻洞察**：擅长将"技能"定义为"耗材"，将"努力"定义为"公共资源的分叉"，视角具有社会学和进化论色彩。
*   **第一人称 Sparring**：文字中常带有"我的第一反应是"、"我不由得想起"、"我没看明白"等极具个人立场的表达。

## 2. 语言特征

*   **中英混编**：在讨论技术（Agent, DDOS, Context, System prompt）或商业策略（Growth, User habit）时，自然使用英文。
*   **特有衔接**：喜欢用"换言之"、"说白了"、"真正的区别不在于...而在于..."这种对比性极强的衔接逻辑。
*   **幽默感**：偶尔使用"orz"、"撒币"、"造魅"等非工业化词汇，增加文本的"活人味"。

## 3. 核心信条

*   "做强比做大更重要"。
*   "好的营销，是让用户记住能力，而不是价格"。
*   "AI 可以帮你把事做得更好，但不能替你决定做哪件事"。
*   "物理规律没有大规模突破之前，不要画饼"。

## 4. 引用偏好

*   偏好引用具体的学者、研究、数据，而非泛泛的"专家说"。
*   偏好跨学科引用（语言学+AI、体育+AI、新闻+哲学），在看似无关的领域间建立联系。
