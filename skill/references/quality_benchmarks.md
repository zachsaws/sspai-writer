# 文章质量审计表

所有由 `sspai-writer` 产生的内容，必须通过以下 5 个维度的硬性审计。

## 五维度评分标准

| 维度 | 硬性指标 (Score 0-10) | 判定红线 (Fail Case) |
| :--- | :--- | :--- |
| **认知张力** | 是否提出了 2 个以上的元问题？是否挑战了读者预期？ | 只有结论，没有追问；平铺直叙，没有反共识。 |
| **颗粒度密度** | 每 500 字是否包含 2 个以上具体物件名/品牌名/精确数据？ | 使用"很多"、"非常"、"极大地"等模糊副词。 |
| **理感耦合度** | 论证段落后是否紧跟了体感细节？（hardcore: 40%, narrative: 70%, mixed: 50%） | 连续三段都是纯逻辑或纯抒情。 |
| **时空对比度** | 是否引入了纵向时间轴或历史演进线？（mixed/narrative 强制要求，hardcore 建议） | 只谈现在，不谈演进。 |
| **去 AI 化** | 衔接词是否具备个人色彩？是否避免了耻辱柱词汇和句式？ | 出现"首先/其次/综上所述/本质上是"。 |

## 审计权重

*   **核心权重 (40%)**：认知张力。如果不能让读者觉得"这事儿没我想的那么简单"，则判定为平庸。
*   **视觉权重 (30%)**：排版呼吸感。单段超过 5 行必须拆分，强调"瀑布流"阅读体验。
*   **余韵权重 (30%)**：留白。结尾必须保留一个悬而未决的问题、一个诚实的遗憾、或一个开放意象。

## 评分输出格式

每轮输出后，在文末附加以下评分表：

```
---
质量审计
| 维度 | 得分 | 说明 |
| 认知张力 | X/10 | ... |
| 颗粒度密度 | X/10 | ... |
| 理感耦合度 | X/10 | ... |
| 时空对比度 | X/10 | ... |
| 去 AI 化 | X/10 | ... |
| 总分 | X/10 | ... |
```

如果任一维度低于 5 分，必须标注**【需重写】**并说明原因。
