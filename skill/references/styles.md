# 风格滤镜 (Style Filters)

用户可以通过指定风格参数来切换输出审美。

## 1. `hardcore` (极致硬核方法论)

- **视觉特征**：大量使用二级标题配合编号列表。段落短小精悍，单段通常 2-4 行。
- **语感特征**：冷峻、精密、像一份系统说明书但带有极强的掌控感。
- **信息密度**：事实 40% + 数据 20% + 体感 20% + 判断 20%
- **转场方式**：逻辑递进为主，辅以数据锚点过渡。
- **代表语料**：《超越效率：10x 提升阅读体验后，我有哪些反思？》、《把阅读作为方法：从选书到笔记的经验分享》。
- **应用场景**：软件测评、工作流分享、硬核教程、效率方法论。

## 2. `narrative` (人文/非虚构叙事)

- **视觉特征**：段落错落有致，单段通常不超过 3 行，留白感强。少用列表，多用段落。
- **语感特征**：温情、细腻、充满电影镜头感（长镜头 + 特写）。
- **信息密度**：事实 20% + 数据 10% + 体感 50% + 判断 20%
- **转场方式**：物理物件锚点、场景切换、时间跳跃。
- **代表语料**：《效率之外，创作的重量》、《二极管感到疼痛之前：那些必须由人讲述的「体商」叙事》。
- **应用场景**：年度征文、生活方式反思、个人经历、创作思考。

## 3. `mixed` (理性与感性的交织)

- **视觉特征**：穿插段落、引用块和金句加粗。标题与正文节奏交替。
- **语感特征**：深刻、博古通今、在社会学观察和个人体感间无缝切换。
- **信息密度**：事实 30% + 数据 15% + 体感 35% + 判断 20%
- **转场方式**：视角抽离（从具体到哲学）、假性终结、跨学科联想。
- **代表语料**：《我们用什么语言思考？》、《AI 十字路口：当机器学会「思考」，我们应该知道什么？》。
- **应用场景**：商业深度分析、科技趋势探讨、认知科学、跨学科思考。

## 4. 风格选择指南

| 用户意图 | 推荐风格 | 判断依据 |
| :--- | :--- | :--- |
| "帮我写一篇产品测评/教程" | hardcore | 结构化、可执行、信息密度高 |
| "我想写一段个人经历/感受" | narrative | 体感优先、留白、电影感 |
| "我想分析一个趋势/现象" | mixed | 理性+感性、认知俯冲、跨学科 |
| 不确定 | mixed（默认） | 最通用，容错率最高 |
